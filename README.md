# Coffee Shop Network Infrastructure

## Project Overview

This project demonstrates the design and configuration of a small business network for a coffee shop using Cisco Packet Tracer.

The network supports management computers, point-of-sale systems, printers, guest Wi-Fi, and network management.

## Network Design

The network includes:

- Router and switches
- Management and office computers
- Point-of-sale terminals
- Office and receipt printers
- Guest wireless access
- Separate VLANs for network segmentation

## VLAN and IP Addressing

| VLAN | Name | Network |
|---|---|---|
| 10 | Management Office | 192.168.10.0/24 |
| 20 | POS | 192.168.20.0/24 |
| 30 | Guest Wi-Fi | 192.168.30.0/24 |
| 99 | Network Management | 192.168.99.0/24 |

## Technologies and Tools

- Cisco Packet Tracer

## Project Objectives

- Design a small business network topology.
- Configure network devices.
- Organize devices using VLANs.
- Configure trunk connections.
- Implement routing between networks.
- Test network connectivity.
- Document the network infrastructure.
